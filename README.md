# ArcMeshComm

ArcMeshComm is a minimalistic Android application designed with a clean and simple user interface, built natively using Kotlin and Jetpack Compose.

## Highlights
- **Jetpack Compose Native**: Fully declarative UI structure.
- **Material 3 Theming**: Out-of-the-box support for System Light and Dark themes.
- **Compose Navigation**: Smooth native routing using a central Navigation Menu.
- **Integrated Help Guide**: A built-in user manual accessible anytime inside the app.

## Documentation
Please refer to the [howtouse.md](howtouse.md) file for comprehensive setup instructions, prerequisites, and a detailed guide on navigating the application.

## Quick Setup
1. Clone the repository or open the folder `ArcMeshComm` in Android Studio.
2. Wait for Gradle to sync completely.
3. Select an emulator or a physical device and press **Run**.
